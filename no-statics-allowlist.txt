# APX-284 — no-statics allowlist
#
# The foundation refactor (docs/foundation-refactor-design.md, APX-278) forbids
# mutable file-scope `static` variables in the foundation module and its
# plugins: every plugin statically links its own copy of sk-foundation, so a
# file-scope static would give host and plugin *separate* copies of the same
# state (the pre-refactor split-logger bug). The guard
# (scripts/check-no-statics.py) only allows `static const` data and `static`
# functions; EVERY other file-scope static must be listed here.
#
# Format: one entry per line, `<path>:<symbol>` relative to the repo root.
# Lines starting with '#' and blank lines are ignored. Keep entries sorted
# within each section. Removing a static from the code also removes the need
# for its entry — the guard reports stale entries as a NOTE.
#
# To regenerate the candidate list after intentional changes:
#   python3 scripts/check-no-statics.py --dump
